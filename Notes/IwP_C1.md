## Vocab
### Recursive
Function that calls itself.

### Call stack 
Controls program's flow of execution.

### Stack
Stores multiple values like a list does.

* limits to adding or removing values from the top of the stack only (like plates).

### Pushing
Adding values to the stack

### Popping 
Removing values from the stack.

### Frames
Contains info about a single function call.

### Frame objects 
Created and pushed onto stack when function is called.

### Recursive function
